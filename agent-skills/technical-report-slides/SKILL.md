# 技術報告スライドの作成

## 目指す成果

読み手が、何の話か、どこを見るか、何が重要かをつかめるスライドを作る。その後、必要な箇所を読むことで内容を理解できる構成にする。

情報の網羅性を、そのままスライドの品質と考えない。必要な内容を選び、関係や違いを見える形にする。システムの編集・保存方法は対象環境の指示に従う。

## 最初に、伝えることと主役を決める

各スライドについて、次の2つを定める。

- このページを見た人に、何を理解してほしいか。
- その理解を担う中心の図・表・画像・文章は何か。

中心となる表現に十分な面積を与える。補足を追加して主役を小さくし続けない。

複数の主題が競合する場合は、現在の主題を絞る。指定された構成や枚数では成立しない場合に限り、ページの分割や構成変更を検討する。

## 内容を、見せる形へ変える

資料の文章を短くして箱に並べるだけで終えない。伝えたい関係に合う表現を選ぶ。

- 違いを伝える：比較対象を対応する位置に並べる。
- 流れを伝える：順序と接続を図にする。
- 全体と部分を伝える：全体の中で対象の位置を示す。
- 仕組みを伝える：働きとつながりを図にする。
- 実際に動くことを伝える：説明と実画面を対応させる。
- 推移や差を伝える：適切なグラフを使う。

これらは選択肢であり、すべてを盛り込むチェックリストではない。説明が単純なら、短い文章だけの構成でもよい。

汎用のカードや箱を均等に並べることを、すべてのページの標準にしない。

## 情報に強弱を付ける

主張、中心の図、補助情報の違いが見えるようにする。すべてを同じ大きさ、太さ、面積で扱わない。

文字の強調は、最初に読む箇所と重要な違いを示すために使う。全文を強調しない。

課題、結論、重要な条件など、注目してほしい情報は、枠で囲む、下線や区切り線を引くなどして、周囲から視覚的に区別する。文字を太くするだけでは埋もれる場合に、積極的に使う。

- 複数の文を一つの課題として読ませたい場合は、まとまりを枠で囲む。
- 短い主張や重要語を強調したい場合は、下線を使う。
- 課題と解決策など、役割の異なる領域を分けたい場合は、区切り線を使う。

枠や線は、何に注目すべきか、どこまでが一つのまとまりかを示すために使う。単なる空間の穴埋めには使わない。

強調する領域には内側の余白を取り、枠や線を文字に密着させない。線の太さや色はテンプレートに合わせ、本文や図を邪魔しない強さにする。

すべての領域を同じ枠で囲まない。重要な箇所を囲み、それ以外を抑えることで主従を作る。

## 文章を増やす前に、図で伝わるかを確認する

図のラベルや実画面から分かることを、補足文で繰り返さない。矢印や配置が関係を伝えている場合、同じ関係を説明する段落を追加しない。

文章は、図だけでは伝わらない主張、意味、重要な条件を補うために使う。

本文を載せるときは、資料の段落をそのまま移さず、そのページで必要な言葉に絞る。ただし、短くするために具体性を失った抽象語へ置き換えない。

補足文、注記、ヘルパーテキストを自動的に追加しない。追加前に、それがなくなると何を誤解するかを確認する。理解も解釈も変わらないなら、載せない。

## 詳細を載せるか判断する

その情報を外すと、主張の意味が変わる、比較が不公平になる、または図を誤読する場合は残す。

そうでない詳細は、そのページの本文へ無理に入れない。必要に応じて、発表者ノート、補足資料、参照元に残す。移動によって依頼された成果物の要件を失わないようにする。

数値、単位、名称、事実は正確に扱う。説明を成立させるための事実を創作しない。

## 参考資料と完成例を使う

参考資料がある場合は、内容だけでなく、何を大きく見せ、何を抑え、どう視線を動かしているかを見る。

忠実な再現を求められた場合は、図形、配置、接続、対比、ラベルまで照合する。元の具体的な表現を、一般的な箱図へ単純化しない。

完成例を参考にするときは、用途が似たページを選ぶ。構成や表現は参考にしても、内容や数値は流用しない。

## 収まらないとき

文字を小さくする前に、次を見直す。

- 同じ内容を二度説明していないか。
- 主題に直接関係しない補足がないか。
- 文章で説明している関係を、配置や図で表せないか。
- 主役に渡すべき面積を、見出しや装飾が使っていないか。

削除すると意味が失われる情報は残す。すべての情報を同じ重要度で保持しようとしない。

## 修正時

成立している構成を起点に、指示された箇所を直す。新しい画像や説明の追加を理由に、それまでの主役や読み順を不用意に変えない。

ユーザーが削除した説明を、親切さや完全性のために再追加しない。

## 実際の表示で評価する

完成前に、ページ全体を見て次を確認する。

- 最初にどこを見るかが明確か。
- 重要な関係や違いを、文章を順番に読まなくてもつかめるか。
- 中心の図や画像が、十分な大きさで見えるか。
- 文字や枠が一様に並び、主従がなくなっていないか。
- 図と文章が同じ説明を繰り返していないか。
- 補足を増やすことで、主役を弱めていないか。

その後、内容の正確さと、理解に不可欠な条件の欠落を確認する。

文章を追加することだけを改善と考えない。削除、配置の変更、強弱の調整によって改善できないかを検討する。
