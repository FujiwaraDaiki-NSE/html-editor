# 技術報告で追加する判断

共通の制作基準は slide-authoring に従う。各ページの目的に応じて、次の説明を選ぶ。すべてのページに同じ構成を要求しない。

- 仕組み：対象、構成要素、それぞれの働きと接続を示す。処理を説明する場合は入力・処理・出力を対応させる。
- 方法・検証：対象、適用条件、評価基準を示す。
- 結果：比較対象、測定条件、結果、解釈を区別する。測定した事実と考察・仮説を混同しない。

図や文章を選ぶ際は、読み手が仕組みや結果を理解するための情報を優先する。証拠が示していない結論や推奨を追加しない。
