- `server/project.mjs` の `agentInstructions`：本文に必要な条件・根拠、標語だけの本文を避ける方針、図表の選択、代表ページの作成、意味と表示の確認。

- `/home/solution2024/.local/state/weave/application-skills/author-slide-preferences/SKILL.md`：説明の具体性、図と実画面の併用、忠実な再現、課題の強調、資料固有の判断を共通化しない方針。
- 同スキルの `references/evidence.md`：2026-10-27に承認されたP01〜P05と、2026-11-17の修正候補の記録。承認済み方針と個別修正からの候補を区別して読んだ。

- 本チャットで整理した2026-11-17の指示：意味を削らない説明文、並列項目を結論に変えない、共通のレイアウト、画像の適切な大きさ、実績の帰属と状態の正確さ。

元の制作チャットや参考PPTXを今回すべて再調査したものではない。既存の根拠ファイルにある履歴要約を、今回直接確認したユーザー発言や完成画面として扱わない。

## 統合した判断

| 知見 | 今回の整理 |
|---|---|
| 説明を減らす／意味を保持する | 図や本文で既に伝わる重複を整理する。理由・条件・因果が失われる削除はしない。 |
| 文字や面積の強弱／並列項目 | 主張と補足の強弱は付ける。同階層の並列項目を結論や付録へ変えない。 |
| タイトルをコンパクトに／大きくする | 本文との階層と識別性を確保し、説明領域と両立する。固定サイズを規定しない。 |
| 図を主役に／画像を見やすく | ページの役割で主役を選び、説明図と実画面を両立する。常に画像を縮小しない。 |
| 全体の統一／汎用カードを避ける | 同じ役割のページ群を揃える。すべてのページを同じ構図へ押し込まない。 |
| 修正から学ぶ／無断更新しない | 再利用できる判断を提案し、ユーザーが確認した内容だけを保存する。 |

## 共通ルールにしなかったもの

- 自己紹介資料の14枚構成、特定ページ番号、案件名、出願件数、AI並列数。
- 特定資料の黒背景禁止、固定の配色、タイトル36px、画像を20〜25%縮小する指定。
- 表紙の「自己紹介」を本文に置く指定、特定のカロリーマップ例を削除する指定。
- 旧実行環境だけに存在する学習ツール・スキル管理画面の名称。
- アプリUI開発向けの `ui-ux-pro-max` 全体。資料制作の共通指示へ、Web/アプリUI設計の規約を一括転用しない。

HTMLのスロット、編集範囲、登録済みクラス、CSSの生成と保存などはハーネスの契約であり、本スキルには複製していない。ハーネスの基本指示と旧スキルの原本は今回変更していない。

## 保存先

- 配布・レビュー用：リポジトリの `skills/slide-authoring/`。
- GUIが管理・更新する実体：html-editor専用のスキル保存先の `slide-authoring/`。

配布用と実体は同時同期ではない。今回の登録後、GUIから育てた実体を配布用ファイルで自動的に上書きしない。将来の再配布時は、実体の最新版との差分とユーザーの承認を確認する。
