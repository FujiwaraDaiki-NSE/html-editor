# 思考をAgentへ渡す機能の提案計画

作成日: 2026-08-11

## 目的

Weaveの「人間の意図とデザインの間にある変換損失をなくす」という思想に沿い、ラフ機能の次に取り組む候補を整理する。

機能の数を増やすこと自体を目的にせず、ユーザーが形を見ながら行う選択・修正・比較・保留を、追加のプロンプト作成なしでAgentへ渡せるかを評価軸にする。

## 進め方

- [x] `concept.md`、注釈レイヤー設計、ラフ機能、複数提案、Agentコンテキストの現状を確認する
- [x] 現在拾えている思考と、まだ失われている思考を整理する
- [x] 機能候補を共通の設計原則と優先順位で比較する
- [x] 最優先候補の具体的な操作フロー、Agentへ渡すデータ、非スコープを定義する
- [x] ユーザー向け提案資料をHTMLで作成する
- [x] 内容と表示を確認する

## 成功条件

1. 各案がプロジェクト思想との接続を説明できる
2. 「何を作るか」だけでなく、人間のどの思考が現在失われているかを示す
3. 既存のラフ、直接編集、複数提案、git履歴を再利用する
4. PowerPoint的な描画ツールや複雑なプロンプトフォームへ寄らない
5. 次に実装する1機能を選べる粒度まで優先順位をつける

## 非スコープ

- この計画内での機能実装
- 永続データ形式やAPIの確定
- 既存の注釈レイヤー設計の変更

## 結果

- 提案資料: [docs/intent-handoff-features.html](../docs/intent-handoff-features.html)
- 最優先案: ユーザーの直接修正を変更前後のお手本としてAgentへ渡す「この直し方を広げる」
- 次点: 複数提案から良い部分を摘む機能、Agentから指示面へ局所的に問い返す機能
- 確認: タグの対応、`git diff --check`、Chrome headlessで1440×1000表示を確認
