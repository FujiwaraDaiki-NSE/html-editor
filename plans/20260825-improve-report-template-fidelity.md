# 年度末報告テンプレート再現度改善計画

## 目的

原本HTMLを再調査し、Weaveの空レイアウトとして利用できる範囲で、年度末報告資料の見た目とレイアウト構造を忠実に再現する。

## 実施内容

1. 原本22枚の共通フレームと表紙・目次・章区切り・通常本文の差を抽出する。
2. 現行 `year-end-report` テンプレートとの差を、座標・色・文字・余白・装飾単位で整理する。
3. Weaveのテンプレート適用仕様に適合する空枠として、必要なレイアウトvariantを最小構成で実装する。
4. テンプレート一覧、適用、複製、ページ再採番、保存、プレビューを回帰テストする。
5. Chromiumで原本と実装を比較し、レビュー指摘がなくなるまで調整する。

## 完了条件

- 原本固有の本文・画像を混入させず、主要な見た目を再現している。
- アプリのcontent policyとtemplate slot契約を満たす。
- build、全テスト、lint、UI確認が成功する。
