# 100%表示時のキャンバス可視性修正

## 目的

100%表示にしたスライドがエディターUIの背後に隠れず、スクロールによって端まで確認できるようにする。

## 計画

- [x] 100%表示時のキャンバス、スクロール領域、ツールバーの位置関係を再現して確認する。
- [x] 手動ズーム時のスクロール領域と前面UIの余白を調整する。
- [x] 回帰テストを追加し、型検査・単体テスト・ブラウザー表示で確認する。

## 完了条件

- 100%表示でスライドの四辺までスクロールできる。
- ツールバーやステータス表示がスライドの確認を妨げない。
- Fit表示、注釈レイヤー、既存のズーム操作が維持される。

## 確認結果

- 通常の1280×720表示で、ステータスとツールバーがスライドに重ならないことを確認した。
- 高さ600px・500pxでも、両方のUIがキャンバス内に収まり、スライドに重ならないことを確認した。
- ビルド、全148テスト、型検査、Lintが成功した。
