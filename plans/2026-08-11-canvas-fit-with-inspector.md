# インスペクター表示時の100%キャンバス修正

## 目的

インスペクターを開いた通常の編集画面でも、ズーム100%でスライド全体を一度に確認できるようにする。

## 計画

- [x] 現在の100%表示とFit表示の倍率・スクロール状態を比較する。
- [x] 100%を現在の編集領域に対する等倍として扱い、インスペクター開閉に追従させる。
- [x] ズーム操作と表示ラベルの回帰テストを更新する。
- [x] 通常表示、インスペクター開閉、狭い画面でブラウザー確認する。
- [x] ビルド、テスト、型検査、Lintを実行する。

## 完了条件

- インスペクター表示中の100%でスライド四辺が同時に見える。
- インスペクター開閉後も100%表示が領域に合わせて再計算される。
- 100%より拡大した場合のみ、必要に応じてスクロールできる。

## 確認結果

- 1280×720でインスペクター表示中もスライド四辺が100%で同時に見える。
- インスペクターを閉じるとスライド幅が約646pxから約843pxへ広がり、再表示すると自動で収まり直す。
- 110%ではスクロール表示へ切り替わる。
- 高さ600pxでもスライド全体とツールバーが重ならない。
- ビルド、全150テスト、型検査、Lintが成功した。
