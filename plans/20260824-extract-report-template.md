# 年度末報告HTMLテンプレート抽出計画

## 目的

参照HTMLの固有本文・画像・実行用React bundleを持ち込まず、共通の4:3スライドフレーム、赤青アクセント、タイポグラフィ、代表レイアウトを再利用できる単一HTMLテンプレートとして抽出する。

## 成果物

- `examples/digital-year-end-report-template.html`
  - 外部依存のない静的HTML
  - 4:3の印刷対応スライド
  - 表紙、目次、章区切り、本文、カード、比較表、画像枠、まとめの代表レイアウト
  - 実案件の本文、会社名、氏名、日付、ロゴ、スクリーンショットを含めない
  - 差し替え箇所を明示するプレースホルダー文言

## 実装方針

1. 元資料の共通フレームとCSS変数を、読みやすい静的HTML/CSSへ再構成する。
2. ページ番号はJavaScriptでスライド数から自動採番する。
3. キーボード操作は前後移動だけに限定し、外部通信や永続化を行わない。
4. 埋め込み画像は除外し、画像差し替え枠のみ用意する。

## 検証

- HTML構文・危険要素・外部依存をテストする。
- 960×720相当および印刷CSSを確認する。
- 代表レイアウトとプレースホルダーが揃い、固有情報が混入していないことを確認する。
- アプリの既存テストとlintを実行する。
- ローカルUIでスライド表示、前後移動、ページ番号を確認する。
