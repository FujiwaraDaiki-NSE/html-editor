# 年度末報告テンプレートのアプリ対応計画

## 目的

参照HTMLから抽出した意匠を、Weaveのテンプレート一覧で選択・プレビュー・適用できる空のスライド枠として実装する。前回追加した単体HTML成果物は、要件違いのため削除する。

## 要件

- `data-weave-slide`、`data-weave-template`、`data-weave-template-name` を持つ。
- `data-weave-slot="title"` と `data-weave-slot="content"` を各1つ持ち、内容は空にする。
- アプリの固定キャンバス `1280×720` と既存のHTML安全性・Tailwind制約に適合する。
- 元資料の灰色曲線フレーム、赤い上罫、青い下罫、組織名・copyright・ページ番号領域を、テンプレート枠として保持する。
- 新規スライド作成、テンプレート変更、ホバープレビュー、Undo/Redo、保存の既存機能を壊さない。

## 実装

1. 組み込みテンプレート定義へ年度末報告用の空枠を追加する。
2. 必要な装飾は安全なインラインSVGと既存ユーティリティで表現し、必要なCSS追加は最小限にする。
3. 誤って追加した `examples/digital-year-end-report-template.html` と専用テストを削除する。
4. 組み込みテンプレートの検証・seed・適用テストを更新する。
5. スライド追加・複製・削除・移動・Undo/Redo後にページ番号を全体から再計算する。

## 検証

- 対象ユニットテスト、lint、build、全テスト。
- UIでテンプレート一覧表示、新規作成、既存スライドへの適用、プレビュー解除、Undo/Redo、保存を確認する。
