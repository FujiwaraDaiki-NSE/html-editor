html-editor共通スキル

資料ごとのスキルとCodex共通スキルの管理を廃止し、html-editor内の全資料で使う指示を一か所で管理する。

GUI

「スキル」から新規作成、編集、修復、SKILL.mdアップロード、検索、有効・無効の切り替え、削除ができる。適用範囲は常に「html-editor共通」。有効な指示は次のAgent依頼から参照される。実行中の変更はサーバーでも拒否する。

保存と実行

項目仕様
保存先既定はインストール先の .weave/skills。WEAVE_SKILLS_ROOTで明示的に変更可能。
独立性HOMEやCODEX_HOMEを参照してスキルを書き込まない。すべての資料から同じ保存先を使う。
適用Thread作成・再開・分岐・ターン開始時、有効で正常なスキルの名前・説明・本文・参照先を基本指示へ追加する。条件に合うスキルを適用する。
無効状態各スキルの .disabled ファイルで保持する。Codex共通の有効設定は変更しない。

旧データ

旧プロジェクトの .codex/skills とCodex共通の skills は削除・移動しない。旧データは新GUIの一覧には含まれない。必要なSKILL.mdを新GUIでアップロードする。同名のスキルは上書きせず競合として表示する。補助ファイルを含むスキルはフォルダー一式を新保存先へ手動コピーする必要がある。旧プロジェクトの復旧処理は既存データ保護のため維持する。

境界

この変更はeditorの管理対象と追加指示を独立させる。Codexそのものが自動検出するユーザー設定・スキルの全読み込みを隔離する変更ではない。共通スキルの編集はGUIから行い、埋め込みAgentにはプロジェクト用スキルを作らせない。

ユーザーの確認を通じてスキルを育てる

Agentの基本指示に、再利用できるユーザーの修正があった場合だけ学習を提案する手順を追加する。一時的な案件情報や数値を普遍的なルールにしない。Agentはプロジェクト内の .weave/skill-proposal.json へ更新対象・説明・提案本文・理由・根拠となるユーザー指示を出力する。スキル自体には書き込まない。

サーバーは成功した編集ターンの後だけ提案を検証し、editor専用の skill-reviews ディレクトリへ保存する。新しいターンの前に入力ファイルを消して古い出力を使わない。提案の失敗は資料の編集成功を取り消さない。

GUIは該当チャットとスキル画面で確認を求め、現在の本文と保存する全文を表示する。ユーザーが保存ボタンを押したときだけスキルを作成・更新する。見送りは資料の変更を取り消さない。提案後に既存スキルが変わった場合は保存時に競合を返す。既存メタデータと無効状態は保持する。未回答の提案は再読み込み後も残し、見送った同じ内容の提案は再表示しない。
