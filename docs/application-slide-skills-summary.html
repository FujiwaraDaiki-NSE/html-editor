Weave共通スライドスキル

個人用のCodexスキルではなく、アプリ専用の agent-skills/ に制作方針を保存する。全プロジェクトのルートチャットと編集エージェントが同じ実ファイルを読む。

指示とスキルの役割

server/agent-skills.mjs が実行中のアプリルートから絶対パスを組み立てる。chatInstructions と agentInstructions の両方へ読み込み指示を渡す。既存の thread/resume と turn/start による指示更新、新規・再オープン時の AGENTS.md 更新を利用する。

AGENTS.md相当の指示は操作、編集範囲、保存と検証を担当する。technical-report-slides は視覚的な構成と品質基準、author-slide-preferences は合意済みのアプリ共通表現方針を担当する。

保存と適用

プロジェクトごとに複製しない。個人用スキルディレクトリにも置かない。既存スキル管理画面の「共通」は個人用ディレクトリを指すため、このアプリ同梱スキルはその画面のCRUD対象ではない。現在の明示指示を優先し、スライド生成・修正時に読み込む。

学習

学習手順と根拠は参照ファイルとして付属する。通常のスライド編集やプロジェクトスキルの変更許可では、アプリ共通スキルを書き換えない。自律学習の実行・保存機構は本変更に含めない。

実行環境

Composeの既存リポジトリマウントにスキルも含まれるため、共有ホームへの追加配置は不要。現在のデプロイは作業用worktreeをアプリルートとして使い、WEAVE_WORKSPACES_ROOTで既存資料の保存先を維持する。

検証

新規・既存プロジェクトが同じスキルを参照すること、共通ファイルを上書き・複製しないこと、ルートチャットと編集エージェントが同じ読み込み指示を受けることをテストする。317件のテスト成功後、ビルド未生成で失敗したSSRテストをビルド後に再実行して成功（計318件）。稼働コンテナ内の両スキル読込先、既存19枚の資料内容不変、GUIでの描画とAgent接続を確認した。表示品質そのものの評価は、実際のスライド制作による別の検証が必要。
