ホームの読み取り専用共有と参照パス登録

ユーザーの許可に基づき、WEAVE_HOST_HOME全体を読み取り専用でマウントする。制作リポジトリ、Codex状態、復旧データの既存書込マウントは維持する。

登録と読み取り

POST /api/references/folderはホーム内の実パスを検証し、references/index.jsonに名前とsource、storage="linked"を記録する。pathは一覧と添付の識別に使う論理パスであり、フォルダー自体は作成しない。ファイル数と容量はnullとし、再帰走査・コピー・索引作成を行わないため、登録上限は設けない。

送信時は添付の論理パスを保存済み索引と照合し、sourceを再検証してAgentのコンテキストに含める。クライアントが申告したsourceは採用しない。Agentにはsourceを参照専用として読むことを指示する。

互換性と削除

既存のコピー資料とPCからのアップロードを維持する。PCからの転送は従来の容量・ファイル数制限を継続する。パス登録の解除は索引だけを変更し、参照元を削除しない。ホーム内リンクと隠しフォルダーを一覧に含め、ホーム外へ解決されるリンクは除く。

運用

参照パスは現在のホスト環境に依存し、元ファイルの変更が次の読み取りに反映される。別ホストへ移す際は登録先を確認する。読み取り専用のホームの下でも、明示的な書込用子マウントの範囲では書込可能である。

確認

2,000ファイル超・500 MB超のフォルダーをコピーせず登録できること、実パスの照合、元データの更新反映、解除時の非削除、既存コピーとの互換性をテストする。Composeの実効マウントと実コンテナでの読取・書込拒否、GUIでの登録と自動添付も確認する。
