PCのフォルダーを参照資料へ追加

「＋ フォルダーを追加」がサーバー内の一覧を開いていたため、ブラウザーを操作するPCのフォルダーを選択できなかった。Dockerではマウント済みのパスだけが一覧に出ていた。

操作

「＋ フォルダーを追加」はPCのフォルダー選択画面を開く。サブフォルダーの階層を保持してプロジェクトのreferencesへ保存し、応答が成功した後に送信対象へ自動選択する。読み込み中と結果は参照資料パネル内に表示する。従来の機能は「サーバーのフォルダーを追加」に残す。

APIと保存

POST /api/references/folder/uploadはmultipartの各フィールド名を相対パスとして受け取る。ファイル数2,000、合計500 MBを上限とし、絶対パス・親ディレクトリへの移動・重複パス・複数のルートを拒否する。隠しファイルを除外し、ステージング先に保存後、フォルダーと索引を公開する。保存失敗時は途中のファイルを削除する。受信中にプロジェクトが変わった場合は409を返す。

PCから取り込んだフォルダーはコピーとして保持する。サーバー側の参照元を持たないため、サーバーの同期ボタンは表示しない。追加済みの同名フォルダーは上書きせず連番を付ける。

検証

バイナリ・日本語パス・空ファイル・階層保持、パストラバーサル、重複、上限、保存失敗のロールバックをテストする。GUIでは追加ボタンからフォルダー選択画面が開くことと、保存後の選択状態を確認する。
